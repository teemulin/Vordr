# TASK-011 — UI Skeleton

## Goal

Create the initial user interface for Vordr.

The UI should establish the application layout without implementing any functionality.

---

## Requirements

- Display the application title:
  - Vordr
- Add a "Start Camera" button.
- Add an empty video preview area.
- Use semantic HTML where appropriate.
- Keep styling minimal.
- Do not implement camera access.
- Do not implement WebRTC.
- Do not implement WebSocket communication.

---

## Acceptance Criteria

- [ ] Application title is displayed
- [ ] Start Camera button is visible
- [ ] Empty video preview area is displayed
- [ ] Layout renders correctly
- [ ] pnpm typecheck passes
- [ ] pnpm build passes

---

## Out of Scope

- Camera functionality
- Authentication
- WebRTC
- WebSocket
- Remote streaming
- Recording

---

## Completion Checklist

- [ ] Requirements implemented
- [ ] Acceptance criteria verified
- [ ] Documentation updated
