# TASK-010 — Static Frontend Hosting

## Goal

Serve the frontend application through the Fastify server.

The frontend should be accessible directly from the root URL while keeping the implementation simple and production-ready.

---

## Requirements

- Serve the frontend build from the Fastify server.
- The root URL (/) must load the frontend.
- Keep the implementation minimal.
- Do not add API endpoints.
- Do not add authentication.
- Do not add WebRTC functionality.

---

## Acceptance Criteria

- [ ] Frontend is served by Fastify
- [ ] Root URL (/) loads the application
- [ ] pnpm typecheck passes
- [ ] pnpm build passes

---

## Out of Scope

- Camera access
- Authentication
- WebRTC
- WebSocket
- API implementation

---

## Completion Checklist

- [ ] Requirements implemented
- [ ] Acceptance criteria verified
- [ ] Documentation updated
