# Vordr Development Tasks

This directory contains implementation tasks for the Vordr project.

Each task represents a small, self-contained piece of work that can be implemented independently.

Tasks are designed to be understandable by both human contributors and AI coding assistants.

## Workflow

Project Vision
↓
Specification
↓
ADR (if required)
↓
Task
↓
Implementation
↓
Tests
↓
Documentation
↓
Pull Request
↓
Merge

## Task Status

Tasks may have one of the following states:

- Planned
- In Progress
- Review
- Completed
- Blocked

## Rules

Every task should:

- have a clear goal
- define acceptance criteria
- define out-of-scope items
- reference relevant ADRs
- reference AGENTS.md
- be small enough to complete in a single pull request
