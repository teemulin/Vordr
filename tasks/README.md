# Vörðr Development Tasks

This directory contains implementation tasks for the Vörðr project.

Each task represents a small, self-contained piece of work that can be implemented independently by a human developer or with AI assistance.

Tasks describe **what** should be implemented—not **how** it should be implemented.

Every implementation should follow the Engineering Handbook and the project's engineering principles.

---

## Development Workflow

Every implementation follows the same workflow.

Engineering Handbook
↓

↓

## Task Format

Each task includes:

- Goal
- Requirements
- Acceptance Criteria
- Out of Scope
- Implementation Notes
- Completion Checklist

Tasks should remain:

- Small
- Independent
- Reviewable
- Easy to understand

---

## AI-Assisted Development

AI coding assistants may be used to implement tasks.

All AI-generated code must be reviewed by a human developer before being committed to the repository.
